# open-data-ai-analytics

## Мета
Створити модульний проєкт для аналізу відкритих даних про дорожньо-транспортні пригоди (ДТП) та відпрацювати роботу з Git: гілки, коміти, Pull Request, злиття в main, вирішення merge-конфліктів і створення тегу релізу.

## Джерело відкритих даних
Набір відкритих даних (ДТП 2015) з порталу data.gov.ua:  
https://data.gov.ua/dataset/dtp2015/resource/5f479fab-2e01-42d6-932d-3748d32d3a09

## Питання / гіпотези для аналізу
1. **Сезонність (В):** кількість ДТП протягом року нерівномірна - у певні місяці/пори року ДТП більше.
2. **Час доби:** найбільша кількість ДТП припадає на години пікового руху (ранок/вечір).
3. **Фактори тяжкості:** частка ДТП з постраждалими/загиблими (або важкими наслідками) залежить від типу/причини ДТП та умов (за наявності відповідних полів у наборі).

## Модулі проєкту
- `data_load` - завантаження даних
- `data_quality_analysis` - перевірка якості даних
- `data_research` - дослідження/аналіз даних
- `visualization` - візуалізація результатів

## Структура репозиторію
- `data/` - дані та опис
- `notebooks/` - ноутбуки для EDA/аналізу
- `src/` - вихідний код модулів
- `reports/figures/` - збережені графіки
