# open-data-ai-analytics

Лабораторна робота 1
Тема: робота з Git (гілки, Pull Request, merge-конфлікти), модульна структура Python-проєкту для аналізу відкритих даних (data_load, data_quality_analysis, data_research, visualization).
Мета: створити репозиторій з правильною структурою проєкту для аналізу відкритих даних та закріпити практичні навички роботи з Git (гілки, коміти, Pull Request, злиття в main, розв’язання merge-конфліктів і створення тегу релізу), реалізувавши модулі завантаження даних, перевірки якості, дослідження та візуалізації


## 1. Створення репозиторію

Було створено віддалений репозиторій **open-data-ai-analytics** на GitHub (порожній, без автоматичного README/.gitignore). На комп’ютері створено локальну папку проєкту, ініціалізовано Git-репозиторій командою `git init` та підключено віддалений репозиторій командою `git remote add origin`. Перевірено підключення командою `git remote -v`.

## 2. Додавання структури проєкту

Локально створено базову структуру проєкту відповідно до вимог: файли `README.md`, `.gitignore`, `data/README.md` та директорії `notebooks/`, `src/`, `reports/figures/`. Далі зміни було підготовлено до коміту через staging area (`git add .`), зафіксовано комітом та відправлено у віддалений репозиторій командою `git push -u origin main`.
